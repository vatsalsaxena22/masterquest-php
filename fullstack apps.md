# 10 Full Stack App Ideas (Traditional Stack)

### 1. **Simple To-Do List**

* Add, edit, delete tasks.
* Store tasks in MySQL.
* Basic HTML forms + PHP backend.
* Focus on CRUD operations.

---

### 2. **Contact Form with Email**

* Simple contact page with form validation.
* Send emails using PHP `mail()`.
* Store submissions in MySQL.

---

### 3. **Guestbook**

* Visitors can leave comments.
* Show all comments on a page.
* Add admin panel to approve/delete comments.

---

### 4. **Basic Blog**

* CRUD posts (create, read, update, delete).
* User authentication for admin.
* Display posts with pagination.

---

### 5. **User Registration & Login System**

* User signup/login/logout.
* Password hashing.
* Session management.
* Profile editing.

---

### 6. **Event Booking System**

* Users can view events and book tickets.
* Admin panel to create/edit events.
* Store bookings with user info.

---

### 7. **Simple E-commerce Store**

* Product listing with images.
* Add to cart + checkout.
* Order management.
* Payment integration (e.g., PayPal sandbox).

---

### 8. **Forum / Discussion Board**

* Users can create topics, reply to posts.
* Nested replies.
* Moderation by admins.

---

### 9. **Inventory Management System**

* Track products, suppliers, and stock levels.
* Add/Update/Delete inventory items.
* Generate reports on stock.

---

### 10. **Content Management System (CMS)**

* Admin interface to create/manage pages, posts, users.
* Role-based access control.
* Media uploads.
* WYSIWYG editor integration.
